I'm a software engineer passionate about building **AI systems that solve real-world problems** rather than simply integrating APIs.

My interests lie at the intersection of **Artificial Intelligence**, **Backend Engineering**, and **Distributed Systems**, where software architecture meets modern machine learning.

# 🧠 Engineering Philosophy

The more I learn, the more I realize that building AI systems isn't just about models.

It's about designing reliable software around those models.

A few principles I try to follow:

✔️ Build before abstracting.

✔️ Understand systems from first principles.

✔️ Keep architectures modular.

✔️ Optimize for maintainability over cleverness.

✔️ Learn by implementing rather than memorizing.

✔️ Design systems that are observable, scalable, and easy to debug.

I believe understanding *why* something works is far more valuable than simply knowing *how* to use it.
