## 🧠 Neuronix

> **Building a Deep Learning Library from Scratch**

Neuronix is an educational deep learning library where every component is implemented from first principles.

Instead of relying on PyTorch or TensorFlow, the goal is to understand the engineering behind modern deep learning frameworks by implementing everything manually.
